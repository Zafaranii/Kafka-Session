Topic notification-requests deck §03–04 · append-only log, offsets, partitions

Each partition is its own append-only log. New records are added on the right; nothing is changed or removed by reading. Each consumer group just keeps a pointer: the offset it will read next.

Brokers deck §04 · cluster & replication

Every partition has 3 copies (one per broker). The leader takes the writes; followers copy it. In-sync followers form the ISR. A write is acknowledged only once at least 2 in-sync copies have it.

Consumer groups deck §05 · groups, partitions → consumers, replay

Each group reads the whole topic independently. Inside a group, every partition goes to exactly one member.
